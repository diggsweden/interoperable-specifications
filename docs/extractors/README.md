# INSPEC extractors

Extractors describe how interoperable specification parts are extracted from other specification parts, see the [rules for extracting specification parts - EXTRACT-INSPEC](../rules.md#rules-for-extracting-specification-parts---extract-inspec). Each extractor defines an extraction standard in the sense of [Rule EXTRACT-1](../rules.md#extract1). The extractors are not part of the core INSPEC specification.

Extractor | Extraction standard | Description
--- | --- | ---
[UML](uml.md) | `inspec-uml:UML` | The INSPEC UML extraction standard, for UML models such as Enterprise Architect files or XMI exports.

The terms used by these extractors are defined in the [INSPEC extractors data vocabulary](../../datavoc/extractors/).

The extractors listed here are those maintained alongside INSPEC. The list is not exhaustive: an extraction standard may be defined elsewhere, and a consumer may support extraction standards not listed here.
